化学渗透学说

电子下坡 · 质子爬坡 · ATP 被拧出来

1961 年，米切尔（Peter Mitchell）提出：呼吸链里电子顺电势「下坡」放出的能量，并没有直接塞给 ADP， 而是先拿去把 H⁺ 从膜的一侧泵到另一侧，存成一道跨膜的质子电化学梯度；H⁺ 再顺梯度回流， 穿过 ATP 合酶这台旋转马达，才把 ADP + Pi 拧成 ATP。

膜是一座水电站 ——
H⁺ 是被抽上去的水，ATP 合酶是水轮机。

自己试三次，比读十遍有用：

  • 把 DNP 拉到 100% —— 看：梯度瞬间塌掉、ATP 归零、但电子传递反而更快、能量全变成热。这就是「解偶联」。

02 / 拆开看

五步：能量是怎么被「搬」过去的

整个学说的骨架只有五步。考研答题时按这五步写，逻辑不会断。

  1. 01筑坝：造一道不漏水的膜

    线粒体内膜（细菌则是质膜）对 H⁺ 几乎不通透：磷脂双分子层的疏水核心把质子挡在外面，膜蛋白又排得极密。

    没有这道「坝」，泵出去多少漏回来多少，能量存不住。所以膜的不通透性本身就是学说的一部分，不是背景条件。

  2. 02泵质子：电子下坡，拉着质子爬坡

    复合体 I、III、IV 都是质子泵。电子在它们内部传递时释放的自由能，驱动蛋白构象变化，把 H⁺ 从基质（N 侧）泵到膜间隙（P 侧）。

    一对电子：NADH 路线泵 4+4+2 = 10 个 H⁺；琥珀酸路线绕开复合体 I，只泵 4+2 = 6 个。这就是 P/O 比差异的全部来源。

  3. 03存梯度：两种能量叠在一起

    泵出去的是电荷，也是酸。于是形成两个分量：Δψ（膜电位，外正内负）和 ΔpH（外侧更酸）。两者合起来就是质子动力势 Δp。

    Δp = Δψ + 2.303RTF·ΔpH ≈ Δψ + 59·ΔpH  (mV, 25 ℃)

    约定：Δψ = ψ外 − ψ内，ΔpH = pH内 − pH外。两式符号必须配套，否则会算反。

  4. 04回流：质子必须「还回去」

    H⁺ 从膜间隙经 F₀ 的通道流回基质，顺着电化学梯度「下坡」，释放的自由能约 20 kJ/mol 每质子。

    关键：这条路只对 H⁺ 开。如果质子从别处漏回去，能量就不经过 ATP 合酶而直接变成热 —— 那是解偶联剂干的事。

  5. 05拧出 ATP：一台真正的旋转马达

    质子流带动 F₀ 的 c 环旋转 → 中央 γ 亚基跟着转 → F₁ 三个 β 亚基依次经历 松散 L → 紧密 T → 开放 O，一步结合 ADP+Pi，一步压合成 ATP，一步释放。

    这就是博耶的结合改变机制（binding change mechanism），他因此获 1997 年诺贝尔化学奖。「酶会转」这件事，是化学渗透学说最漂亮的证据。

它推翻了什么？

化学偶联假说（旧）

电子传递时生成一种「高能中间物」A~B，它直接与 ADP 反应生成 ATP。

✗ 找了几十年，谁也没分离出这个中间物。

→

化学渗透假说（Mitchell）

能量先转成物理形式——跨膜质子梯度，再由梯度驱动 ATP 合成。

✓ 梯度真的存在（可测），而且能人工制造。

这个假说的革命性在于：能量不必以化学键的形式中转，它可以暂时以「膜两侧的电荷差 + 酸度差」这种物理形式存着。 后来的「局部质子耦合」「膜表面质子池」等修正，只是改细节，不改骨架。

四条经典证据，考简答可以直接写

①重组脂质体

把细菌视紫红质（只泵质子、不传电子）和 F₀F₁ 一起装进人造脂质体。光照 → 内部变碱 → 合成 ATP。

没有任何电子传递链参与，仅靠光驱动的质子泵就够了。

②人工梯度

把叶绿体类囊体或线粒体放在酸性缓冲液里「喂」一夜，再突然注入含 ADP+Pi 的碱性液，暗中也能爆出一批 ATP。

只造了 pH 差，没有电子传递，也能合成 —— 决定性的。

③解偶联剂

2,4-二硝基苯酚（DNP）是脂溶性的弱酸，能带着 H⁺ 穿过膜。梯度被「短路」，ATP 停止，而电子传递反而加速、全部能量变热。

历史上 DNP 曾被当成减肥药，因为它在「烧」能量而不让它变成 ATP —— 结果致命，早已禁用。

④呼吸控制

加寡霉素堵住 F₀，质子回不去，梯度升到顶，电子传递链被「憋」得跑不动，耗氧量骤降。

反过来说：只要解偶联剂把梯度放掉，耗氧量立刻回升 —— 这是「梯度在调控呼吸」的直接证据。

05 / 算一算

这道梯度到底值多少钱

拖动滑块，看 Δp 和每个质子的「含金量」。这是判断「能量够不够合成一个 ATP」的标准算法。

25 ℃ 下 2.303RT/F = 59 mV。设置负值可以看看「反向」时会发生什么。

质子动力势 Δp 209 mV
  • 每个 H⁺ 回流的自由能 |ΔG|20.2kJ/mol
  • 理论 H⁺/ATP（c/3）2.67
  • 含 Pi 转运后实际 H⁺/ATP3.67
  • 合成 1 个 ATP 的「能量成本」74kJ/mol
  • 生理条件下 ATP 水解 ΔG≈ 50kJ/mol
结论—

为什么必须 3 个以上质子？生理条件下合成 1 个 ATP 需要约 50 kJ/mol，而 1 个质子过膜只放出约 20 kJ/mol。 50 ÷ 20 ≈ 2.5，再加上 Pi 转运和腺苷酸交换的额外消耗，实际落在 3～4 之间。 这就是「化学渗透」在数量上的自洽：不需要任何神奇的高能中间物，普通的热力学就够了。

06 / 微生物篇

细菌没有线粒体，照样玩得转

学微生物的时候，最容易把线粒体的那套图硬套到细菌上。其实结构换了、方向换了，道理一个字没变。

细菌的呼吸链是「可换件」的

大肠杆菌一条链上可以有多种脱氢酶和多种末端氧化酶，按氧气多少切换：

  • 好氧：末端氧化酶把电子交给 O₂。
  • 硝酸盐呼吸（反硝化）：终末受体是 NO₃⁻ → NO₂⁻ → NO → N₂O → N₂。
  • 硫酸盐呼吸：终末受体是 SO₄²⁻，产物 H₂S。
  • 延胡索酸呼吸：终末受体是延胡索酸，产物琥珀酸。

受体换了，但「泵质子 → 造梯度 → 回流做 ATP」这条主线一模一样。所以厌氧菌也能氧化磷酸化，只是末端受体不是氧。

最纯粹的证据：细菌视紫红质

盐沼盐杆菌（Halobacterium salinarum）的紫膜上只有一种蛋白 —— 细菌视紫红质。它吸收光子后直接把一个质子从胞内搬到胞外，完全不传电子。

整个细菌就靠这一台「光驱动质子泵」造出梯度，再用 F₀F₁ 做 ATP。这是化学渗透学说最干净的活体证明，也是第 04 节那个脂质体实验的原型。

梯度还能拿来干别的

  • 驱动鞭毛：鞭毛马达靠 H⁺（或 Na⁺）回流转动，不是直接烧 ATP。
  • 次级主动运输：乳酸菌等靠质子同向转运吸收乳糖、氨基酸；反向转运排出 Na⁺、抗生素。
  • 耐酸机制：质子泵把误入胞内的 H⁺ 泵出去，维持胞内 pH 稳定。
  • 逆电子传递：硝化细菌、硫氧化细菌靠 Δp「倒着推」电子，把 NAD(P)⁺ 还原，供 CO₂ 固定用。耗能，但必要。
  • 产热：部分细菌和褐色脂肪组织一样，用解偶联蛋白把梯度直接变成热。

考研常考的一句话：原核生物的氧化磷酸化在细胞膜上进行，质子被泵到细胞外；真核生物在线粒体内膜上进行，质子被泵到膜间隙。两者的化学渗透机制完全相同。

07 / 考点

高频考法与易混点

下面这些是这块内容真正会被问到的角度。点开每一条看要点。

化学渗透学说的基本要点（简答题模板）
  1. 线粒体内膜（细菌质膜）具有质子不通透性，是能量转换的结构基础。
  2. 呼吸链的电子传递与质子泵出相偶联，把 H⁺ 从 N 侧泵到 P 侧。
  3. 被泵出的质子不能自由返回，形成跨膜质子电化学梯度（Δψ + ΔpH = Δp）。
  4. H⁺ 经 ATP 合酶 F₀ 通道顺梯度回流，释放自由能。
  5. 回流的能量通过 F₁ 的构象变化（结合改变机制）驱动 ADP + Pi → ATP。
  6. 因此 ATP 合成的直接能源不是电子，而是质子梯度。
氧化磷酸化、底物水平磷酸化、光合磷酸化，三者怎么分
类型能量来源是否需要膜与梯度例子
氧化磷酸化电子传递释放的自由能需要线粒体内膜、细菌质膜
光合磷酸化光能驱动的电子传递需要叶绿体类囊体膜、紫膜
底物水平磷酸化高能底物基团转移不需要糖酵解、TCA 中的琥珀酰 CoA

记忆钩子：只要答案里出现「膜」「梯度」「ATP 合酶」，就是化学渗透路径；出现「~P 直接转移」，就是底物水平磷酸化。

P/O 比为什么是 2.5 和 1.5（而不是老书的 3 和 2）

P/O 比 = 每消耗 1 个氧原子（即每对电子传给 ½ O₂）所酯化生成的 ATP 分子数。

  • NADH 路线：复合体 I 泵 4 + III 泵 4 + IV 泵 2 = 10 个 H⁺；10 ÷ 4 ≈ 2.5。
  • 琥珀酸路线：绕过复合体 I，只有 4 + 2 = 6 个 H⁺；6 ÷ 4 ≈ 1.5。

老教材用「每 ATP 需 3 个 H⁺」估算，于是得 10/3 ≈ 3、6/3 = 2。差别只在质子/ATP 的折算系数，不是机制变了。

「为什么」类分析题的通用思路

所有这类题都走同一条推理链：某环节被动了 → 梯度怎么变 → 回流量怎么变 → ATP 怎么变 → 电子传递受不受反馈抑制 → 耗氧和产热怎么变。

ATP 合酶的结构细节
  • F₀：疏水，嵌在膜内，组成 ab₂cn；c 环是质子通道兼转子。寡霉素结合在 F₀。
  • F₁：亲水，伸向基质，组成 α₃β₃γδε；α 和 β 交错排成六聚体。
  • 催化位点全在 β 亚基上，三个位点构象不同、轮流工作。
  • γ 是中央旋转轴，与 ε 一起随 c 环转；δ 连接 F₁ 与 F₀ 的 b₂。
  • 三种构象：L（松散）结合 ADP+Pi → T（紧密）催化成 ATP → O（开放）释放 ATP。
易混点速辨
一对概念区别
电子传递链 / 氧化磷酸化前者只是「传电子」，后者是「传电子 + 磷酸化」的全过程，需要 ATP 合酶参与。
呼吸链 / 光合链前者最终把电子交给 O₂（或其它末端受体），后者光激发电子后循环回到起点。
抑制剂 / 解偶联剂堵通路 vs 开旁路。前者 ATP 与耗氧一起降，后者 ATP 降而耗氧升。
Δψ / ΔpH电荷分量 vs 浓度分量，二者共同构成 Δp，可以互相部分转化。
F₀ / F₁膜内的质子通道（旋转）vs 膜外的催化头（合成）。
